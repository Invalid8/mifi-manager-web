# MiFi Manager

A modern web application for managing and monitoring MiFi (Mobile WiFi) devices. This project provides an intuitive interface to control, configure, and track your MiFi device performance.

## Features

- **Device Management**: Monitor and manage your MiFi device settings
- **Real-time Monitoring**: Track connection status and performance metrics
- **User-Friendly Interface**: Clean and responsive design for easy access
- **Dark Mode Support**: Seamless dark/light theme switching

## Getting Started

To get started with MiFi Manager, clone the repository and install dependencies:

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to access the application.

## About

MiFi Manager is designed to simplify device management and provide users with essential insights into their mobile connectivity devices, all from a single web interface.
